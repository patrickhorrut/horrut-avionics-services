HORRUT AVIONICS SERVICES — SITE WEB

1. Ouvrir index.html dans un navigateur pour voir le site.
2. Pour le publier gratuitement, créer un dépôt GitHub public nommé votre-identifiant.github.io, puis y importer index.html, availability.json et le dossier assets.
3. Dans GitHub : Settings > Pages > Deploy from a branch > main / root.
4. Le site sera accessible à https://votre-identifiant.github.io/ (si le dépôt porte ce nom).

CALENDRIER :
Le fichier availability.json contient les jours confirmés, sans aucune donnée inventée.
Exemple de contenu :
{
  "dates": {
    "2027-01-04": "free",
    "2027-01-05": "busy"
  }
}
"free" = disponible, "busy" = occupé. Les autres dates restent non renseignées.
Modifier ce fichier sur GitHub met à jour le calendrier public après publication.
Les modifications locales ne sont PAS automatiquement synchronisées sur le site en ligne.

ATTENTION : le site est public et contient le numéro de téléphone et l'e-mail autorisés par le propriétaire.
Les qualifications et privilèges doivent être revérifiés avant publication ; ne pas interpréter la liste de types comme une preuve de certification en vigueur.
Le logo et la bannière sont des créations graphiques et non des photos documentaires d'un aéronef réel.
